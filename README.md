## Классы

- `StudentRecord` — запись таблицы (`NamedTuple`): `student_id`, `first_name`,
  `second_name`, `age`, `sex`.
- `Database` — абстрактный класс: проверка данных, `create_record`,
  `select_record`; способ хранения скрыт в методе `_save`.
- `MemoryDatabase` — реализация `Database`, хранящая таблицу в оперативной памяти.
- `TUI` — консольное меню; принимает любой объект `Database`, функции ввода и
  вывода можно подменить (это используется в тестах).

## Ограничения данных

| Поле          | Ограничения                        |
|---------------|------------------------------------|
| `student_id`  | целое положительное, уникальное    |
| `first_name`  | непустая строка                    |
| `second_name` | непустая строка                    |
| `age`         | целое от 1 до 150                  |
| `sex`         | `M` или `F` (регистр не важен)     |

## Запуск

Требуется Python 3.10 или новее. Из корня репозитория:

```
python -m src.db
```

## Тесты

```
python -m unittest discover -s tests -t .
```

Покрытие (нужен пакет `coverage`: `pip install coverage`):

```
coverage run -m unittest discover -s tests -t .
coverage report --include="src/*"
```
