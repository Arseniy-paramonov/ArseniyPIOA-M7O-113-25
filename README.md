Прототип СУБД, работающей в оперативной памяти (in-memory), с одной таблицей
`Student` и консольным интерфейсом.

## Структура проекта

```
PIOA-M7O-213BV-25/
├── src/
│   └── db/
│       ├── backend/
│       │   ├── __init__.py
│       │   └── memory.py   # таблица и операции над ней
│       ├── __init__.py
│       ├── __main__.py     # точка входа
│       └── tui.py          # текстовый интерфейс
└── README.md
```

- `backend/memory.py` — хранилище: таблица `Student` (список кортежей), функции
  `create_record` и `select_record`, проверка данных.
- `tui.py` — меню, ввод и вывод данных, обработка ошибок ввода.
- `__main__.py` — запуск программы.

## Таблица Student

| Поле          | Тип | Ограничения                       |
|---------------|-----|-----------------------------------|
| `id`          | int | положительное, уникальное         |
| `first_name`  | str | не пустое                         |
| `second_name` | str | не пустое                         |
| `age`         | int | от 1 до 150                       |
| `sex`         | str | `M` или `F` (регистр не важен)    |

## Функциональность

1. Добавление записей (`create_record`).
2. Чтение записей с фильтрацией по одному или нескольким полям
   (`select_record`); без фильтров выводятся все записи.
3. Обработка ошибок: некорректные данные, повторяющийся `id`, нечисловой ввод
   (программа переспрашивает и не завершается аварийно).
4. Консольное меню: добавить, показать все, найти по фильтру, выход.

## Запуск

Требуется Python 3.10 или новее. Из корня репозитория:

```
python -m src.db
```
